# Resume Project Entry

## Synchronous RAM + FIFO

- **Project Title:** Verilog Design and Verification of Synchronous RAM-Based FIFO
- **Bullet 1 (technical):** Designed a parameterized synchronous FIFO in Verilog with integrated RAM storage, pointer-based flow control, and full/empty status management to ensure predictable data movement across continuous read and write operations.
- **Bullet 2 (simpler):** Created simulation tests for startup behavior, queue limits, overflow handling, and data order, confirming the design worked reliably and transferred data correctly from input to output.
